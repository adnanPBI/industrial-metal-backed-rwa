# Sepolia verification records

`sepolia-demo.json` is created **only after a successful two-token Sepolia deployment**, including 2-confirmation transaction receipts and on-chain readback of chain ID, bytecode, metadata, supply and access control. A missing manifest means there is no verified deployment to report.

There must be no Mainnet deployment here. Never add private keys, signer seed phrases, RPC credentials or payment terms to this directory.
