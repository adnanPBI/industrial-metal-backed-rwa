# ReserveChain mobile application scaffold

This is the shared-backend mobile foundation required by the master scope. The current build is deliberately **pre-launch gated**: wallet, purchase, live Proof-of-Reserves and redemption flags are false. The app reads program/configuration data from the same ReserveChain REST API used by the web ecosystem.

A production milestone still requires owner-controlled Apple Developer/App Store Connect, Google Play Console, Firebase/push credentials, KYC integration, secure authenticated participant endpoints, MFA, wallet-signature flow, device/session controls, TestFlight and Play closed testing, store privacy declarations, screenshots, signing/keystore handover and store review corrections. Those third-party/account tasks cannot be completed from this offline package alone.
