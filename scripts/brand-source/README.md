# Canonical Copper/Nickel brand sources

The definitive Copper/Nickel SVGs are `public-demo/public/assets/img/reservechain-logo.svg`, `reservechain-wordmark.svg`, and `reservechain-wordmark-light.svg`. The matching WordPress theme copies must have exactly the same bytes. The legacy October-27 compressed multi-commodity source files were retired; they no longer represent the approved identity.

Run `python scripts/install_brand_assets.py` for a read-only check, or `python scripts/install_brand_assets.py --install` to synchronize the WordPress copies from the canonical public files. No image is represented as evidence of title, custody or reserves.
