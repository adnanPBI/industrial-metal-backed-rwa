# ReserveChain Demo Fixtures

These files are **ILLUSTRATIVE / DEMO DATA ONLY** for local development, integration tests, screenshots, and reviewer walkthroughs.

They are not evidence of current ownership, custody, insurance, reserves, token issuance, investor eligibility, redemption rights, or an active offering. Production records must be created only from owner-approved source documents and the configured review/publication workflow.

Included fixtures:

- `asset-programs.json` - Copper Powder and Nickel Wire sample program records based only on the supplied IGAS certificate facts already approved for the demo.
- `digital-asset-passports.json` - illustrative DAP records linked to the two initial programs.
- `proof-of-reserves.json` - intentionally non-live reserve dashboard states with no fabricated reserve quantities.
- `waitlist.json` - fictitious `.example` contacts for UI/testing only.
- `audit.jsonl` - sample hash-chain-shaped audit events for interface development; production audit events are generated by the application.
