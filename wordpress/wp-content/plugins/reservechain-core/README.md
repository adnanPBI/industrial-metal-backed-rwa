# ReserveChain Core WordPress plugin

Activation creates structured ReserveChain tables, roles, two initial asset-program records and the 51-page sitemap.

Public REST namespace: `/wp-json/reservechain/v1`.

Admin modules: Control Center, Asset Programs, Waitlist, Audit Log and Settings.

The plugin deliberately does not implement a public token purchase, wallet or live redemption endpoint in pre-launch mode.
