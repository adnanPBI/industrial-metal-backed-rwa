# ReserveChain Blue Glass Visual System

The v0.2 interface keeps ReserveChain's institutional navy/black base but changes the application surfaces to layered blue glass rather than flat panels.

- Base: near-black navy (`#020916`) with deep blue radial illumination.
- Glass: translucent navy/blue surfaces with 18-22px backdrop blur where supported.
- Lines: restrained cyan-blue borders, never neon-heavy.
- Primary accent: cyan/sky blue for data, active states and navigation feedback.
- Secondary accent: ReserveChain gold only for brand emphasis and selected commercial/asset highlights.
- Cards: lifted glass panels with internal highlight, soft blue shadow and hover elevation on desktop.
- Forms: dark translucent fields with visible blue focus rings.
- Portals/admin: left glass navigation rail + data surface architecture consistent with institutional dashboards.
- Accessibility: text remains high contrast; focus states remain visible; decorative motion is suppressed by reduced-motion preferences.
